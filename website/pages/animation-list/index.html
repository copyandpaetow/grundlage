raf-animation-list

Each bar is produced by mapping over an array, and every frame the entire list reconciles with fresh values — a worst-case stress for list diffing and per-frame allocation. The animation self-drives; measure hands its rAF loop to the shared measureWindow harness for a wall-clock window and reports fps, frame time, DOM writes per frame, and heap delta. Run under DevTools CPU throttle to find the cliff.

One live component at a time — changing the bar count remounts it, so no second rAF loop runs alongside and skews the measurement.
