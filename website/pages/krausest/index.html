krausest bench

Runs the canonical js-framework-benchmark operation suite (create, replace, partial update, select, swap, remove, append, clear) against the current renderer. Median over N samples, with one warmup pass and a double-rAF gate so each measurement includes layout + paint.

Save a baseline before you optimize — the vs baseline column then flags any op that drifts more than 2% from the saved median. Suite results are also logged as JSON to the console for stashing in bench/.
