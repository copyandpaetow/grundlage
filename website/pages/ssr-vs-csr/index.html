SSR vs CSR

Same component, same async fetch, same first-yield template. The difference is whether the lib's server pass already painted the result into the HTML before this page reached your browser.

CSR (no server pass)

The host element is empty in the HTML. The browser parses it, the generator runs, the await fires, then the first yield writes the card. You see an empty dashed box for the duration of the fetch.

SSR (first-yield prerendered)

A vite plugin (see vite.config.ts) ran the lib in server mode at transform time. The <template shadowrootmode> with the first-yield content is already in the response — instant paint, no flash. On hydration the client generator's matching yield wires bindings without overwriting the server text.
