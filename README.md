# Grundlage

A small, vanilla-flavored, zero-dependency library for building web components with tagged template literals.

```bash
npm install grundlage
```

The documentation lives next to the code:

| package                                               | what it is                                                    |
| ----------------------------------------------------- | ------------------------------------------------------------- |
| [`grundlage`](lib/README.md)                          | the library: components, templates, props, SSR and hydration  |
| [`vite-plugin-grundlage`](prerender-plugin/README.md) | prerenders components into the HTML as declarative shadow DOM |
| [`website`](website)                                  | demo and measurement pages, built with grundlage              |

[`lib/llms.txt`](lib/llms.txt) is the condensed reference for coding agents.
